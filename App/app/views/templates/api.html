POST /api/predict

Send a student's features as JSON with your token in the Authorization header. model is "B" (default, no demographics) or "A" (all features). Missing fields default to 0.

curl -X POST {{ base_url }}/api/predict \
  -H "Authorization: Bearer {{ new_token or 'YOUR_TOKEN' }}" \
  -H "Content-Type: application/json" \
  -d '{"model": "B", "cumulative_gpa": 3.27, "ela_sbac_sd_units": 0.36, "math_sbac_sd_units": 1.25}'

Response:

{"model": "B", "probability": 0.752, "risk_score": 75, "risk_category": "red"}

Risk categories: green 0–33, yellow 34–66, red 67–100.
